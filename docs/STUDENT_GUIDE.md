## 1. 登入系統

### 步驟

1. 打開瀏覽器，前往老師提供的網址（例如 `http://localhost:3000`）。
2. 等待頁面顯示 **伺服器在線** 後，點選 **「學生」** 角色。
3. 選擇你所屬的 **教室**（可透過搜尋框快速查找）。
4. 從名單中選擇 **你的名字**。
5. **首次登入**：系統會要求你設定密碼（至少 4 個字元），請記好這個密碼。
6. **之後登入**：直接輸入密碼即可進入。

> **提醒**：你的帳號由老師事先建立，無法自行註冊。如果找不到你的名字，請聯繫老師。

## 2. 主介面總覽

登入後會看到學生主介面，主要分為三個區域：

| 區域 | 位置 | 說明 |
|------|------|------|
| **側邊欄** | 左側 | 練習專案列表、課堂作業列表 |
| **程式編輯器** | 中央 | 寫程式的主要區域，支援語法高亮與自動補全 |
| **對話面板** | 右側/浮動視窗 | 師生對話、AI 提示 |

頂部工具列包含：語言切換、執行按鈕、舉手按鈕、主題設定、登出按鈕。

## 3. 程式編輯器

### 支援語言

- **Python**
- **JavaScript**
- **Java**
- **C++**

可透過頂部的語言選單切換。編輯器具備語法高亮、自動補全（IntelliSense）等功能。

### 常用快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Ctrl + /` | 註解/取消註解 |
| `Ctrl + Z` | 復原 |
| `Ctrl + Shift + Z` | 重做 |
| `Ctrl + D` | 選取相同文字 |
| `Ctrl + F` | 搜尋 |
| `Tab` | 縮排 |
| `Shift + Tab` | 反向縮排 |

### 拖放檔案

你可以直接把本機的程式檔（`.py`、`.js`、`.java`、`.cpp` 等）**拖放到編輯器**中，系統會自動載入檔案內容（檔案大小上限 1 MB）。

### 即時同步

你在編輯器中寫的程式碼會**自動同步**給老師，不需要手動儲存或送出。老師可以即時看到你目前的程式碼。

## 4. 練習專案

練習專案是你的個人程式庫，可以用來保存課堂練習、實驗或個人作品。

### 建立專案

1. 在左側側邊欄找到 **「練習專案」** 區域。
2. 點選 **「新增專案」** 按鈕。
3. 輸入專案名稱，選擇語言。
4. 新專案建立完成，可以開始寫程式。

### 建立資料夾

- 點選 **「新增資料夾」** 按鈕來建立資料夾。
- 資料夾可以幫你分類不同的練習主題。
- 可以用**拖曳**的方式把專案移動到不同資料夾中。
- 資料夾支援展開/收合。

### 儲存專案

- 在編輯器中修改程式碼後，點選 **「儲存」** 按鈕，即可將目前的內容存入練習專案。

### 刪除專案/資料夾

- 點選專案或資料夾旁的 **刪除** 圖示即可移除。

## 5. 課堂作業

### 查看作業

- 左側側邊欄的 **「課堂作業」** 區域會列出你所屬教室的所有作業。
- 作業分為 **「進行中」** 和 **「已截止/已關閉」** 兩個群組，可點選展開或收合。
- 每個作業會顯示：作業名稱、截止時間、剩餘時間、提交狀態。

### 作答作業

1. 點選你要作答的 **作業項目**。
2. 編輯器會切換到作業模式，開始寫你的答案。
3. 也可以將本機檔案**拖放到作業項目**上，直接載入程式碼。

### 提交作業

1. 在截止時間前，點選 **「提交」** 按鈕。
2. 提交成功後會顯示提交時間。
3. **在截止前可以重複提交**，系統會保留你的最新版本。

### 將作業存為練習專案

- 點選 **「存為練習專案」** 按鈕，可將目前的作業程式碼一鍵保存到你的練習專案中，方便日後複習。

## 6. 執行程式碼

### 執行方式

1. 在編輯器中寫好程式碼。
2. 點選頂部的 **「執行」** 按鈕（▶）。
3. 執行結果會顯示在下方的輸出面板。

### 支援執行的語言

| 語言 | 是否可執行 |
|------|-----------|
| Python | ✅ 可執行 |
| JavaScript | ✅ 可執行 |
| Java | ❌ 僅編輯（暫不支援執行） |
| C++ | ❌ 僅編輯（暫不支援執行） |

### 輸入（stdin）

如果你的程式需要使用者輸入（例如 Python 的 `input()`），系統會提供輸入框讓你輸入測試資料。

### 注意事項

- 程式執行有 **時間限制**（約 10–15 秒），超時會自動中止。
- 輸出上限約 10,000 字元。

## 7. 舉手發問

遇到問題需要老師幫忙時：

1. 點選頂部工具列的 **「舉手」** 按鈕 ✋。
2. 老師端會看到你的舉手通知，會盡快過來協助。
3. 如果不再需要幫助，可以再次點選 **「取消舉手」**。

## 8. AI 提示

每個練習專案都有獨立的 AI 助教對話，可以在寫程式遇到困難時尋求提示。

### 使用方式

1. 先選擇一個 **練習專案**（AI 提示需在練習專案中使用，非作業模式）。
2. 開啟右側的 **AI 提示** 面板。
3. **首次使用時**，你需要提供題目資訊（以下任一方式）：
   - 直接輸入題目文字
   - 貼上題目網址
   - 上傳題目截圖（≤ 4 MB）
4. 輸入你的問題，例如「這題的邏輯應該怎麼想？」
5. 也可以直接點選 **「請給我提示」** 按鈕快速發問。

### AI 回應原則

- AI 只會提供 **提示和類似範例**，**不會直接給出完整答案**。
- 回覆支援 **Markdown 格式與表格**，方便閱讀。
- 每個練習專案的對話紀錄會自動保存，下次開啟同一專案可以繼續對話。

## 9. 師生對話

你可以和老師進行一對一的文字對話。

### 使用方式

1. 點選右側/浮動的 **「師生對話」** 面板。
2. 在輸入框中輸入訊息，按下 **傳送**。
3. 老師的回覆會即時顯示在對話視窗中。

### 提示

- 當有 **未讀訊息** 時，對話圖示會顯示提示標記。
- 打開對話視窗後，未讀訊息會自動標記為已讀。
- 對話視窗可以**調整大小**。

## 10. 教室倒數計時

- 老師可以為教室設定倒數計時（例如：作業作答時間）。
- 倒數計時會**即時顯示**在你的畫面上。
- 最後 **5 分鐘**時會以醒目顏色提醒。
- 時間到時會顯示 **「時間到」**。

## 12. 常見問題

### Q: 我找不到我的名字？
**A:** 你的帳號是由老師建立的，請聯繫老師確認帳號是否已經建立、是否在正確的教室中。

### Q: 我忘記密碼了？
**A:** 請聯繫老師，老師可以協助重設你的密碼。

### Q: 為什麼我的程式碼執行失敗？
**A:** 請檢查以下幾點：
- 程式碼是否有語法錯誤
- 是否選擇了正確的程式語言
- 程式是否執行超時（超過 10–15 秒）
- Java 與 C++ 目前不支援執行

### Q: 作業截止了還能提交嗎？
**A:** 作業截止或關閉後就無法再提交，請務必在截止時間前完成提交。

### Q: AI 提示沒有回應？
**A:** 請確認你是在「練習專案」模式下使用 AI 提示，且已提供題目資訊。如果仍有問題，可能是 AI 服務暫時無法連線，請稍後再試或聯繫老師。

### Q: 頁面顯示「伺服器離線」？
**A:** 表示後端伺服器未啟動或網路連線異常，請聯繫老師確認伺服器狀態。

### Q: 我的程式碼會被保存嗎？
**A:** 是的。你在編輯器中的程式碼會即時同步到伺服器，練習專案手動儲存後也會保存在資料庫中。
